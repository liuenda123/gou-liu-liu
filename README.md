# 狗遛遛

义乌本地遛狗服务微信小程序 MVP。

## 当前版本

这是第一版可运行原型，使用本地模拟数据，不需要 AppID、服务器或微信支付商户号即可导入微信开发者工具预览。

已包含：

- 首页与附近遛狗员展示
- 发布遛狗需求入口
- 宠物管理入口
- 订单入口
- 遛狗员详情页
- 模拟下单流程

## 导入方式

1. 下载或克隆本仓库。
2. 打开微信开发者工具。
3. 选择“导入项目”。
4. 项目目录选择 `miniprogram`。
5. AppID 暂时选择测试号或不填写。
6. 点击编译预览。

## 目录结构

```text
miniprogram/   微信小程序前端原型
docs/          产品和开发文档
server/        后端开发预留目录
admin/         管理后台开发预留目录
```
